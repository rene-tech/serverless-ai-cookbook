# Sources and adaptation

Reviewed 2026-10-24. Adapted from K-Dense's MIT `immunologist` profile:
https://github.com/K-Dense-AI/scientific-agents/tree/98c7fae46648724e1a43a1f2b207b0c82fcc462e/scientific-agents/immunologist
(copyright K-Dense, Inc. 2026; `../LICENSE-K-DENSE-MIT`). The adaptation keeps
conceptual/analysis guidance, avoids fixed wet-lab recipes or unsupported package
claims, and separates conventional CAR from peptide–MHC recognition.

- Immune epitope evidence: https://www.iedb.org/ (distinguish experimental records
  from predictions and verify assay/species/HLA).
- AIRR standards and repertoire data: https://docs.airr-community.org/
- MIFlowCyt: https://pubmed.ncbi.nlm.nih.gov/18752282/
- MIATA framework: https://www.miataproject.org/
- Existing donor-aware analysis evidence: https://www.nature.com/articles/s41467-021-25960-2
- CAR-T primary sources, data access and model limits: read the separate
  `car-t-research` skill's research map only when relevant.

Consult current primary papers for a specific mechanism. Neither a named standard
nor an AI-generated checklist establishes formal compliance or scientific validity.
