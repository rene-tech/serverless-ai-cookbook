## Contract and retained behavior

- Execution keeps the platform's native job/session ID. Artifact, local study
  and consultation IDs identify different objects; they are not job aliases.
- REST/MCP helpers use the exact discovered current schema. MD/scVI/MPI wrapped
  requests and staged flat requests are distinct supported execution families,
  not old-version fallbacks. Uploads use `upload_id` independently of jobs.
- Inline reports require the current authenticated `/workspace/preview` API
  handler and matching UI. The paired maintenance procedure preserves the API
  process, owned state and original download capability; static-only updates
  cannot supply the route. Old immutable assets remain for already-open tabs.
- Current progress uses scientific units, rates and freshness; GPU placement
  stays private. Durable studies retain admission receipts and never replay an
  uncertain submission. Explicit temporary admission refusals may retry only
  within the existing bound and with the same idempotency key.
- CPU preparation, optional mdprecheck, artifact viewers, bucket persistence,
  managed-agent customization and account access remain part of the release.
